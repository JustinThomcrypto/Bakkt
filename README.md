Client Activation and Success Hub

An interactive work sample built for the Client Success Manager position at Bakkt.

Live: https://justinthomcrypto.github.io/Bakkt/

Simulates a book of five institutional trading and payments clients moving from signed agreement through activation, launch, and renewal, with an activation tracker, a cross-functional action center, and a QBR.
